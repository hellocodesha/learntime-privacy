LearnTime: Earn Screen Time (学后时光) · Updated November 8, 2026

Short practice first, then an agreed amount of entertainment time. This page covers setup, earned time, purchases, and what to check if a restriction does not appear.

Getting started

  1. Install LearnTime on the iPad or iPhone the child uses.
  2. Open the parent area. Set a six-digit parent password and save the recovery code somewhere safe. The code is shown only during setup and when you change the password.
  3. On a child device in Apple Family Sharing, approve the Family Controls authorization request. This step needs a parent's Apple account approval.
  4. Select individual entertainment apps. Choose a time reward, the number of questions per round, and a daily earning cap.
  5. Enable the rules, then try opening one of the selected apps to check that the system restriction appears.

Simulator and device limits

The simulator can preview content, setup, and the reward flow, but it does not restrict other apps. Real device restrictions need correct signing, a child device in Family Sharing, and a parent's approval. Simulator results are not proof that a restriction works on a physical device.

Earning and using time

Finish a practice round and correct any mistakes to earn the agreed minutes. Tap Start play time, then return to the Home Screen and open a selected entertainment app. The app does not display a live countdown; it relies on the system's usage thresholds. When the earned time is used up, the selected apps are restricted again. Come back to LearnTime to start the next round.

After the daily earning cap is reached, practice can continue without adding more entertainment time.

Why is there no live countdown?

LearnTime uses the system's app-usage thresholds to end a session. It does not run a foreground timer and does not claim second-by-second accuracy. The system may deliver a threshold callback with some delay.

Does ending a session early return the unused minutes?

No. Ending a session early, changing the rules, or selecting a different app ends the current session, and unused allocated minutes are not returned. Minutes that were earned but not yet used remain until the end of the day.

I forgot the parent password

On the parent verification screen, choose the recovery-code option. Enter the recovery code saved during setup, then set a new password and save the new recovery code. The old recovery code stops working. If both the password and the recovery code are lost, there is no online recovery service. Do not rely on reinstalling: Keychain items may remain after reinstalling.

Restore purchases and manage a subscription

Open the parent area and choose Restore Purchases using the Apple account that made the purchase. Learning Plus is available as a monthly or yearly auto-renewing subscription or a one-time purchase. Manage or cancel a subscription in the Apple account settings. A one-time purchase does not renew. Actual prices are shown on Apple's purchase screen.

A restriction did not appear

  • Check that the parent authorization is still approved and that the rules are enabled.
  • Confirm the app is selected individually. Whole categories, websites, LearnTime itself, and essential communication apps should not be selected.
  • Open a selected app after saving the rules; the system applies the restriction at the device level.
  • System permission changes, device state, and OS issues can affect restrictions. LearnTime does not claim to be impossible to bypass.
  • To pause restrictions temporarily, a parent can disable the rules in the parent area.

What the app does not do

  • It does not control televisions or read video content.
  • It does not provide remote management from a parent's phone.
  • It does not sync allowances across devices. Each device has its own settings.
  • It does not guarantee second-level accuracy or complete bypass prevention.

学后时光支持

LearnTime: Earn Screen Time(学后时光)· 更新日期:2026 年 11 月 8 日

先完成短练习,再使用约定的娱乐时间。本页说明设置、兑换、购买,以及限制没有出现时该检查什么。

开始使用

  1. 在孩子使用的 iPad 或 iPhone 上安装学后时光。
  2. 进入家长区,设置六位家长密码,并把恢复码保存在安全的地方。恢复码只在首次设置和修改密码时显示。
  3. 在 Apple 家庭共享的儿童设备上,批准 Family Controls 授权请求。这一步需要家长的 Apple 账户批准。
  4. 逐个选择娱乐 App,设置每轮题数、每轮奖励和每日赚取上限。
  5. 启用规则后,尝试打开一个所选 App,确认系统限制出现。

模拟器与真机限制

模拟器可以预览内容、设置和奖励流程,但不会限制其他 App。真机限制需要正确签名、家庭共享中的儿童设备以及家长批准。模拟器结果不能证明真机限制已经生效。

赚取和使用时间

完成一轮练习并订正错误后,会获得约定的分钟数。点击开始娱乐,回到设备主屏幕,打开家长选定的娱乐 App。App 不显示实时倒计时,而是依赖系统的使用阈值。额度用完后,所选 App 会再次被限制。需要手动回到学后时光开始下一轮练习。

达到当天赚取上限后,仍可继续练习,但不会再增加娱乐时间。

为什么没有实时倒计时?

学后时光使用系统的 App 使用阈值来结束时段,不在前台运行计时器,也不承诺精确到秒。系统回调可能有延迟。

提前结束会退回未使用的时间吗?

不会。提前结束本次娱乐、修改规则或更换所选 App 都会结束当前时段,未使用的已分配分钟不退回。已经赚取但尚未使用的分钟保留到当天结束。

忘记家长密码怎么办

在家长验证页选择使用恢复码。输入首次设置时保存的恢复码,设置新密码并保存新的恢复码。旧恢复码会失效。如果密码和恢复码都遗失,当前没有在线找回服务。不要依赖卸载解决:钥匙串信息可能跨重装保留。

恢复购买与管理订阅

进入家长区,使用原购买账户选择恢复购买。学习进阶可选择月度/年度自动续订或一次性购买。订阅在 Apple 账户设置中管理或取消。一次性购买不会自动续费。实际价格以 Apple 购买页为准。

限制没有出现

  • 检查家长授权是否仍然有效,规则是否已启用。
  • 确认是一步步单独选择 App。不要选择整个类别、网站、本 App 或必要通讯工具。
  • 保存规则后,重新打开一个所选 App;系统会在设备层面应用限制。
  • 系统权限变化、设备状态和系统问题可能影响限制。学后时光不承诺完全无法绕过。
  • 需要临时取消限制时,家长可以在家长区暂停规则。

App 不提供的能力

  • 不控制电视,不读取视频内容。
  • 不提供家长手机远程管理。
  • 不跨设备同步额度,每台设备独立设置。
  • 不保证精确到秒或完全防绕过。
